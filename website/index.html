Features

Everything a board repair tech needs

From opening the file to closing the repair — BoardScope covers the entire diagnostic workflow in one tool.

📋

Interactive Boardview

Pan, zoom, and click any component or net. Supports .brd, FlexBV, Verilog Boardview, and ASCII formats. Renders both sides simultaneously.

🔍

Net & Component Search

Type any net name or part reference and BoardScope highlights every connection across the board — instantly. Multi-search finds shared nets between two components.

⚡

Voltage Measurement Log

Record live voltage readings per net. Color-coded pass/fail overlays update the board view in real time. Export as CSV for documentation.

🗺️

Volt Map & Diode Map

Overlay measured voltages as a heat map across the board. Diode mode overlays forward-voltage readings with short/open detection — spot faults at a glance.

🌡️

Thermal Map

Load a thermal camera image and align it over the board to correlate hot spots with specific components and power rails.

🤖

AI Diagnosis

Describe the symptom and let the AI analyze your board, measurements, and fault patterns. Supports Anthropic, Google Gemini, OpenRouter, and local Ollama models. PRO

⚠️

Fault Tree

Step-by-step guided repair trees for MacBook, Dell, HP, Lenovo, Nintendo Switch, and more. AI-generated trees for any symptom on any board.

🔌

Power Tree & Sequencing

Visualize the full power architecture — which rail enables which. Power Sequence Timeline shows the expected power-up order with live voltage markers.

📝

Repair Notes & History

Per-component and per-net notes, repair logs, before/after measurement diff, community notes shared across your team, and video reference links.

💧

Liquid Damage Tools

Map corroded areas, score severity by zone, and track reballing workflows for BGA chips — all overlaid on the boardview.

🎬

Macro Recorder

Record your measurement sequences and replay them on every board of the same model. Consistent, repeatable diagnostics at scale. PRO

✅

Post-Repair Test Suite

Define automated test sequences that verify each rail and measurement point after a repair. Pass/fail report exports to HTML or PDF. PRO

Workflow

From file to fix in minutes

BoardScope is built around the real workflow of board repair — not around theory.

01

Load the board file

Drag in any .brd file. BoardScope parses it instantly — components, nets, pads, and both board sides rendered with zoom and pan.

02

Identify the fault area

Use the Fault Tree to follow a guided symptom path. Search rails, trace signal paths, and use the Short Finder to locate bridges.

03

Probe and measure

Record voltages per net directly in the app. Connect a serial multimeter for live readings with stable-reading detection and auto-fill.

04

Repair and verify

Run the Test Suite to confirm every rail is back in spec. Export a pass/fail report and log the repair for the board model's history.
